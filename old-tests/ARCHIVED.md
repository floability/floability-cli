# Archived tests

These files are the previous Floability test suite, moved here unchanged. They
are intentionally outside pytest's configured `tests/` collection directory.

Do not treat this directory as a passing suite. It contains useful test ideas,
real service URLs, data-cache scenarios, fixtures, and assertions, but also
stale assumptions, duplicated coverage, large downloads, and inconsistent
markers. Adopt behavior from it incrementally into `tests/` after simplifying
and verifying each case against the current implementation.
