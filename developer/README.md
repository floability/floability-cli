# Developer archive

This directory collects historical developer material that is useful while
Floability is being stabilized but is not part of the user documentation or
the active test suite.

- `implementation-docs/` contains design notes and implementation summaries.
  They describe earlier development decisions and may not match current code.
- `old-tests/` contains the archived test suite. Pytest does not collect these
  files; the maintained tests are in the repository's top-level `tests/`
  directory.

Treat both directories as reference material. We plan to remove them after
their remaining useful knowledge has been incorporated into current code,
tests, or maintained documentation.
